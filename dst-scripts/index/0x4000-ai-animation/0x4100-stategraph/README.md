# `0x41000000` StateGraph

This directory covers the StateGraph runtime, reusable CommonStates helpers, and the Wilson player graph.

## `0x41001111` Scope

Read the runtime page for scheduling and transitions.
Then read CommonStates for generated states and SGWilson for player actions and prediction.
