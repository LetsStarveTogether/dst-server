# Fieldkit · 随行工具箱

独立的《饥荒联机版》客户端 Mod，版本 **0.15.0**。

## 安装与操作

将本目录复制到游戏的 `mods/fieldkit/`，在客户端模组中启用。
也可在仓库根目录运行 `just package-client-mod`，再解压生成的 `dist/fieldkit.zip`。

| 入口 | 操作 |
| --- | --- |
| 工具箱／停止 | `F6`／`F7`；HUD 也有工具箱、停止按钮 |
| 表情 | 按住 `F8`，指向后松开执行，中心取消；滚轮或 PgUp／PgDn 翻页；面板入口支持点击、方向键与手柄 |
| 常用表情 | 工具箱 `设置八格常用表情`；八个位置固定保存，空位与暂不可用的表情保留位置；翻页仍可使用全部表情 |
| 固定范围 | 世界目标中键／`F9` 切换，双击中键切换附近同类；`F5` 清除；工具箱可输入自定半径 |
| 格型 | `V` 切换最近两种格型；首次为方格／菱形，可改绑 |
| 寻物 | 右侧常驻列表；标题切换搜索范围，地形按钮可选 `当前船／陆地`，点击物品切换组选取，按钮拾取；工具箱可收起或进入手柄控制 |
| 快速烹饪 | `F10` 重复已打开或明确所指的锅；原生锅窗口也有 `重复一次` 按钮 |
| 晾晒 | 工具箱选择所指／选区／附近晾晒架，再选择只收成或身上的补挂原料；先放下光标物品 |
| 海钓 | 装备海钓竿，指向抛竿范围内的海面后打开工具箱，进入 `自动海钓`；可调整本次钓获上限，也可接手已经抛出的鱼线 |
| 自动维修 | 工具箱 `自动维修与补充燃料`，先检查各物品的阈值及允许消耗的材料，再开启本次游戏自动维修；`F7` 或 HUD 停止按钮关闭自动维修 |
| 库存配方 | 打开锅后，`Ctrl+F10` 从所指自身库存／背包槽开始记录，无槽时从物品栏第 1 格；`Shift+F10` 记录背包前格；普通锅四格，调味站两格 |
| 手柄 | 从原生暂停菜单打开工具箱，用方向键、确认、返回操作 |
| 选择 | `Alt` + 左／右键点选或框选；双击同类多选，增加 `Ctrl` 移除 |
| 地图 | 大地图 `Alt` + 右键导航、`Shift` 追加航点；小地图直接右键导航 |
| 虫洞 | 穿越并观察到两端后，大小地图显示相同配对编号；信息面板可隐藏编号或清除本世界记录 |
| 航行 | 在船上装备船桨，或先操作舵轮，再通过地图选择海面航点；手柄划船会先走到对应船边 |
| 跟随／推挤 | `Shift` + 左键跟随可见玩家、生物或气球；增加 `Ctrl` 推挤满足碰撞条件的目标 |
| 库存 | 槽位滚轮取／放一个，增加 `Ctrl` 批量；中键转移整堆，`Ctrl` 中键转移指定数量，`Shift` 中键收集同类至鼠标；持物时无修饰中键收回自身库存／背包 |
| 食谱效果 | 原生食谱书中已吃过的菜品详情可宣告基础效果，支持键鼠／手柄 |
| 效果与天气 | 信息面板查看食物效果倒计时、天气预估和变化记录；HUD 显示最早结束的两个效果与天气 |
| Boss 计时 | 信息面板查看已观察到死亡的蜂后、龙蝇、毒菌蟾蜍、帝王蟹、邪天翁与海象的刷新预估 |
| 驯化记录 | 开启骑乘计时后，在信息面板查看最近骑乘记录；完整观察上牛与甩落时，可估算上牛时刻的驯化范围 |
| 季节鱼 | 可见的季节鱼显示名称与季节颜色；海钓或信息面板可关闭标记 |
| 就地宣告 | `Alt` 点击原生／新增状态、季节盘、时钟、库存／装备或制作配方／单项材料与 WX 芯片；`Shift+Alt` 点击世界目标／空地；增加 `Ctrl` 临时反转全局／附近频道 |

长期设置为 **45 项**，包括功能启停、输入映射、文字尺度、独立感官控制及耗料权限。
**24 项任务与显示参数**在工具箱对应主题或寻物列表内直接调整，保留当前页面与焦点。
数量、附近范围、跟随策略与间距、任务借杖、路线偏好、几何格型与格距、宣告频道属于任务意图；已开始的任务使用启动时捕获的值。
参数在当前游戏会话中保留，HUD 重建不会重置；重新启动游戏使用默认值。
池塘钓鱼和海钓共用钓获上限参数，已开始的任务保留原上限。
配方记忆、小地图展开状态和缩放、维修阈值与材料、八格常用表情保存到本地。
自动维修默认关闭；每类物品可选 0%、10%、25%、50%、75% 阈值，0% 关闭该类物品的维修。
允许消耗的材料逐项勾选，最多保存 32 类物品，每类 8 种材料。
世界观察记录保留最近两个世界／分片；每个世界最多保存 16 对虫洞、16 次骑乘、12 个 Boss 计时、16 个食物效果与 16 次天气变化。
本地资料文件上限为 128 KiB；读取资料期间的本次修改优先生效。
库存修饰键沿用游戏的强制交易／堆叠控制映射；滚轮方向留在配置页，批量数量在工具箱调整。
面板固定打开前的目标和位置，避免菜单打开后鼠标移动改变操作对象。
船上所指位置在面板打开期间随船体移动、转动；平台消失后会提示重新选择。

## 几何摆放与行为队列

墙体、地皮与半地块物件使用各自的原生格点；依赖建筑锚点、岸线或船边的物件遵循游戏的定位与可放置判断。
开启自动格距时，植物人直接播种与耕地共用种植排列，可选 2×2、3×3 或跨地块连续密排。
密排遵守原生土堆最小间距，每地块的坑数随网格位置变化。
框选及工具箱启动的批量施工保留选定朝向；船上选区与施工朝向随船体移动、转动。

连续砍伐、采矿和清除月亮附着物会持续到游戏判定对应动作结束。
浇水、升级、烤食物、施肥、修补、加燃料、添加防腐剂和装填炮弹等操作使用工具箱的 `每个目标最多投入次数`。
目标达到可接收上限后继续处理下一个目标；材料不足或动作被拒绝时停止投入。
工具选择依据原生动作判定，支持符合动作条件的新工具；空水壶会尝试换用可用的备用水壶。
浇水和有限次肥料会逐次确认用量与动作结果，兼容单次用量不足以改变显示百分比的工具。
队列也支持装瓶、修复海洋拖网、刷毛、卸鞍、拆解和移除可铲除物件。

本轮代码核对与自动回归使用游戏脚本版本 **756039**，并直接运行其动作选择、放置、锚点定位等相关函数。

## 使用边界

手动输入、焦点切换、暂停、死亡、角色或世界切换会停止任务。
取消后，已经发生的移料、制作或原生动作不会自动回滚。
库存操作等待真实数量确认；中途取消时，暂存物品留在正常库存槽位。
烹饪队列备料时会等待库存、背包和已打开箱子的数量同步，再判断是否缺料。
远端重复制造需从自身库存或背包耗料；存有同配料的其他制作容器须先关闭，免材料模式使用原生制作。
路线只使用已探索区域；离屏目标只显示最后观察的信息，未知数据不会当作零。
大地图暂停期间可继续计算已选航点的路线；关闭地图后恢复执行前会复核路径。
路线默认偏好道路和适合当前角色的加速地皮，并绕开当前可见的危险目标；工具箱可分别关闭这两项偏好。
寻路分步计算且有复杂度上限；未找到路线时可增加中间航点。
持有鼠标物品时可导航；具备水面移动能力的形态可通过地图跨海移动。
持桨时选择甲板目标会使用原生步行和跳船规则。
海面航点固定在世界位置，抵达按船体中心计算；绕行搜索会检查船体宽度、海岸和附近船只。
航行辅助控制划桨或舵轮，风帆和船锚由玩家操作；到达或停止任务后，船只仍可能受风力和惯性影响。
海钓按鱼线张力收线，确认钓获后继续抛竿，最多运行十分钟；渔获按原生规则落地，可使用寻物列表拾取。
停止海钓辅助会把鱼竿控制交还玩家，仍在水中的鱼线需要手动处理。
`当前船／陆地` 筛选在船上仅显示同船物品，在陆地上仅显示陆地物品；换船会使此前捕获的筛选选择失效。
远端掉落收集依赖客户端可见信息，延迟同步的物品可能遗漏或无法准确判断归属。
自动维修在角色空闲、没有其他任务且库存同步完成时执行；每次消耗等待材料减少与耐久／燃料增加共同确认。
维修失败或结果未确认时，该物品暂停自动处理；调整规则或重新开启自动维修后可再次尝试。
食物效果按已确认进食与公开规则估算；离线期间保留剩余时间，死亡清除效果记录，服务器自定义效果可能不同。
天气预估需要连续有效观测；强制天气、观测不足或同步修正时显示未知。
Boss 倒计时仅表示预计可刷新时间；服务器设置、季节和召唤条件会影响实际出现时间，再次看到存活目标后更新记录。
驯化记录中的估算对应上牛时刻；中途加入、受击、喂食、动作或状态变化会使估算失效，记录仍会保留。
同名牛的记录分别保存；服务器回档会丢弃来自未来的观察记录。
本模组在客户端运行；图形界面、手柄和真实多人网络表现仍需实机验收。
